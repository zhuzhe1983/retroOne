# AI 玩游戏的直播选题

这是配合 [MCP 与观战开发方案](ai-agents.md) 的候选清单，不是已支持游戏表，也不是热度排行榜。2026-10-21 按“看得懂、容易产生选择与意外、观众能参与、视觉 Agent 有机会玩下去”评估；话题性是节目设计判断，不保证流量。游戏是否在自己的库中、当前版本能否启动、联机和输入是否正常，均需单独验证。

| 游戏 | 建议节目 | 多人性质 | 弹幕参与 | 上手顺序与风险 |
| --- | --- | --- | --- | --- |
| 宝可梦 红 / 火红 | 不同模型当队长，带同一支队伍冒险；或平行挑战第一枚徽章 | 多 Agent 商量、一个执行；或独立比赛，不能叫原生联网 | 初始伙伴、命名、队伍、路线投票 | **首选**；回合制战斗给模型思考时间，地图探索仍可能卡住。两版本分别适配，暂不承诺模拟通信交换/对战 |
| 百战天虫 Armageddon（1999 PC） | 两队 AI 互相放话、计算抛物线、偶尔误伤 | 第一版先轮流控制同机；原生联网另测 | 武器、目标或限定挑战投票 | **优先候选**；回合制适合慢决策，但 Windows/Wine 启动和鼠标/键盘控制尚需适配 |
| 超级炸弹人 2 / 3（SFC） | 模型淘汰赛、临时结盟与反转 | SameConsole，各自独立手柄槽；具体人数与转接器配置逐款确认 | 地图、禁用道具、赛制投票 | **第二阶段**；规则容易看懂，但躲炸弹需要快反应，先验证低延迟控制 |
| 拳皇 97（街机） | 模型选手联赛、角色 BP、挑战限定招式 | SameConsole 双方对战；不要把后来的在线重制版能力套给街机 ROM | 选人、队伍和禁招投票 | **后期**；观众熟悉、对局短，纯视觉 LLM 操作频率不足，动作辅助必须公开说明 |
| 怪物猎人 P3 / 自由联合（PSP） | 两 Agent 分工引怪、输出、补给，人类做教练 | 目标是 Network 各自视角协作；这两款在 RetroOne 尚未完成验证 | 任务、武器和配装建议 | **后期**；节目空间大，但建房、反应、长流程与模拟器兼容都更难 |
| 山脊赛车 2（PSP） | 双模型计时赛、驾驶风格对比 | RetroOne 已验证双实例 Network，同场独立视角 | 车辆、赛道与驾驶约束 | **联网技术首测**；已有人工验证基础，不代表 AI 已会驾驶 |

宝可梦的视觉 Agent 玩法有公开先例：Anthropic 描述过让模型看屏幕、通过工具按键推进《Pokémon Red》的实验；这证明这种连接方式可行，不代表任意模型能稳定通关。[实验说明](https://www.anthropic.com/news/visible-extended-thinking)。

选题依据可对照发行方资料：[Worms Armageddon 的同机与在线对战功能](https://store.steampowered.com/app/217200/Worms_Armageddon/)、[Konami 对历代炸弹人玩法的介绍](https://www.konami.com/games/bomberman/collection/us/en/)、[SNK 的原版拳皇 97 介绍](https://www.snk-corp.co.jp/us/games/acaneogeo/kof97/)。这些资料说明游戏玩法，不替代 RetroOne 的运行验证。PSP 网络适配参考 [PPSSPP Ad-hoc 设置](https://www.ppsspp.org/docs/multiplayer/quickstart/)，当前只有 [山脊赛车 2 的项目实测](../NETWORK_REVIEW.md) 可以作为本项目联机已完成的依据。

建议第一场先做“AI 队长玩宝可梦，观众决定队伍和路线”，以可完成的小目标结束，例如获得第一枚徽章；不用把首播目标定为通关。第二场再尝试百战天虫的回合制对战，动作链路成熟后做炸弹人淘汰赛。原生联网工程验证与节目选择可以分开：先用山脊赛车 2 证明两 Agent 的实例、视角和控制确实隔离，再扩展适合合作的游戏。

每期叠加层展示模型名、角色、当前目标、最近动作、比分和投票倒计时。模型卡住时，可由观众选择一条提示或经授权让主持人短暂接管。接管应留记录，与 AI 自主完成区分；测试失败和绕路也可以成为节目的一部分，不用剪成模型从不出错的效果。
