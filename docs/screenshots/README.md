# 界面截图说明

这些 PNG 于 2026-10-19 使用本仓库的网页代码，在无头 Chromium 中实际打开并截图。截图为页面视口，保留 PNG 原始编码，没有合成游戏画面、替换游戏封面或进行截图后的裁剪修图。

为避免公开个人收藏与第三方游戏素材，截图使用隔离的本地示例 API 数据：成员名、游戏名、大小、在线活动、邀请与画面设置状态均为虚构演示资料。所有卡片使用应用自己的文字占位图，头像来自应用内置 SVG。图片内附有“示例界面”标记。

| 文件 | 展示内容 |
| --- | --- |
| [library.png](library.png) | 平台分类、搜索、运行方式筛选、详情和家人在线动态 |
| [members.png](members.png) | 玩家选择、独立档案及新增成员入口 |
| [add-member.png](add-member.png) | 昵称与预设头像选择，未创建任何实际成员 |

| [invitation.png](invitation.png) | 接受或暂时拒绝邀请的界面，未启动任何游戏 |

这些图片用于解释界面，不是模拟器兼容性、实际联机、分辨率生效或性能验证的证据。演示邀请中的虚构条目不会进入正式游戏白名单。截图过程中没有访问或修改正式服务，没有读取 ROM、固件、密钥或第三方游戏图片。文件散列与来源记录见 [manifest.json](manifest.json)。
