拍摄仅浏览页面并读取目录 API，没有新增收藏、修改最近记录、启动或结束游戏。截图浏览器的在线心跳在本地拦截，没有向服务器登记临时在线成员。成员昵称仅在截图页面显示层匿名化，服务器资料保持原样；应用自带的预设头像保留。

真实封面作为界面截图的一部分展示，不另行收录封面源文件。没有请求、复制或公开 ROM、BIOS、固件、密钥及存档。拍摄时后台仍在扫描目录，三张截图的总数可能随拍摄时间增长；逐图时间和实际显示数量保留在清单中，没有为使数字相同而修改界面。

这些图片只能说明游戏库的展示效果，不能证明列表内每款游戏都能启动，也不是帧率或模拟器兼容性测试。
