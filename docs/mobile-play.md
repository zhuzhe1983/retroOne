# 手机游玩

RetroOne 的手机播放器共用浏览器模拟器和云端串流入口。触控只是新增的输入方式，实体手柄、键盘、玩家存档和云端会话沿用原有机制。

## 打开与安装

1. 在 Android Chrome 等浏览器中打开可信的 HTTPS 地址，选择自己的玩家。
2. 进入游戏后自动显示触控按键。如果模拟器先显示“开始游戏”，先点一下画面中的按钮，以启动核心并允许浏览器播放声音。横屏时方向键和动作键分居两侧；竖屏时按键位于画面下方。
3. 点角落的 **☰ → 全屏游戏**。若浏览器拒绝全屏，页面保留沉浸布局和返回菜单入口。
4. 想从桌面启动，可退出播放窗口，在 **顶栏自己的头像 → 安装应用** 中安装；也可以使用浏览器自带的安装菜单。

安装入口是否出现由浏览器决定。普通局域网 HTTP 地址和不受信任的证书通常不具备 PWA 安装条件；使用已经配置好的可信 HTTPS 地址。安装后的窗口不带普通浏览器地址栏，系统状态栏和导航栏仍取决于设备与浏览器。

## 画面与按键

游玩菜单提供：

| 选项 | 作用 |
| --- | --- |
| 原比例居中 | 保持模拟器画面比例，在可用区域内居中；比例不同时会留黑边 |
| 横向铺满 | 保留居中画面的高度，只拉伸宽度；人物可能显得更宽 |
| 触控手柄 | 开关网页按键，连接实体手柄时可关闭以留出画面空间 |
| 按键布局 | 默认按游戏平台选择，也可手动改为经典双键、四键、街机六键、SEGA 六键、PSP、双摇杆或 DOS 键盘 |
| 按键大小、透明度 | 按持握习惯调整；保存在本机浏览器、当前玩家名下 |
| 游戏按键 | START、SELECT、L3/R3 或平台对应系统键；点击后回到游戏并发送一次按键 |
| 模拟器工具 | 暂时收起网页菜单和触控按键，让出完整画面，操作模拟器原有的键盘、存档和设置工具 |

触控游玩或全屏时，顶部工具栏收进菜单，系统键不再单独占用底部一排。云端串流的浮动键盘和侧边工具入口也在正常游玩时隐藏；需要时从 **☰ → 模拟器工具** 打开，用完点 **返回游戏**。返回游戏库、切换玩家和结束游戏仍在菜单中，结束前会再次确认。

方向与动作支持同时按下，虚拟摇杆保留连续幅度。松手、触控取消、切到后台或关闭播放窗口会释放虚拟输入；通信中断时也会自动释放，避免角色一直移动。

不同平台的按键标记不同。例如任天堂使用 B/A/Y/X，PlayStation 使用 ×/○/□/△，街机提供六个动作键和投币、开始。DOS 默认提供方向键、Enter、Esc、Space、Ctrl、Shift、Alt；个别游戏需要进入模拟器重新映射。自动布局依据平台，不能判断每款游戏的全部特殊操作。

这些选项只调整客户端布局和输入，**不会提升模拟器内部渲染分辨率，也不会修改服务器画面设置**。图像自身的黑边、双屏主机布局仍由模拟器决定。

## 存档、返回和更新

在 **☰ → 模拟器工具** 中使用浏览器模拟器原有的保存、载入和导出工具。普通游戏存档与保存状态的区别见 [README 的存档说明](../README.md#保存与恢复进度)。

返回游戏库会保留云端游戏；结束游戏仍需确认。PWA 安装不会把云端存档改存到手机，也不会自动备份浏览器存档。

应用仅缓存自己的图标和离线提示页，不缓存游戏库页面、玩家 API、ROM、存档或串流。断网后不能启动游戏。发现新版本时不自动刷新当前页面，关闭同一站点的页面与应用窗口后，再打开即可采用等待中的更新。

## 验证边界

自动检查覆盖多指状态合并、松手和断连释放、输入来源校验、浏览器模拟器桥接、Selkies 手柄协议、PWA 缓存与更新生命周期。移动布局与全屏还需要在真实浏览器中检查。

浏览器的手机视口模拟不能代替实体 Android 的系统栏、软键盘、触控手感及安装验证。部分浏览器的全屏和安装行为不同；目前不承诺所有平台的触摸屏、鼠标或专用外设玩法都能用标准虚拟手柄完成。
