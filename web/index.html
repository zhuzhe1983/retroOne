键盘与手柄

WASD / 方向键选择游戏，Enter 确认，Esc 返回，/ 搜索。Xbox 或 PlayStation 手柄默认启用，连接后按任意键唤醒：十字键 / 左摇杆选择，A / × 确认，B / ○ 返回，LB / RB（L1 / R1）切换平台，Menu / Options 切换玩家。

进入游戏后，按键映射与存档由对应模拟器管理。请在游戏菜单中查看和调整。

两种方式，一个游戏库

支持的 20 MB 以内游戏在本机浏览器运行。较大的游戏通过服务器运行并串流画面；每位玩家使用独立的云端游戏会话。

目标为流畅的 60 FPS；实际表现取决于原作帧率、模拟器、设备与网络。标为“待配置”的游戏需要补齐运行环境。

游戏进度与连接

浏览器游戏的普通存档保存在当前设备的浏览器中（IndexedDB）。点击模拟器“保存状态”会下载存档文件，并同时备份到服务器，可在播放器顶部载入或导出。

云端游戏的存档持久保存在 NAS，结束前请先在游戏内保存。关闭串流窗口会保留云端会话，点击“结束云端游戏”才会关闭模拟器。
