# 界面语言

顶栏和玩家选择界面的语言菜单提供简体中文、English、跟随浏览器。初始默认简体中文；自动模式使用浏览器语言列表中第一个受支持的中文或英文，其他语言回退简体中文。

未选玩家时，偏好保存在当前浏览器。选定玩家后，网页读取该玩家的 `/api/settings/interface`；语言偏好写入其持久化配置目录下的 `interface-settings.json`，与画面设置、收藏及存档分开。更换浏览器后选择同一玩家即可读取偏好。

切换语言不会启动、停止或重新加载游戏。RetroOne 网页立即更新；已经打开的模拟器保留当前状态，浏览器模拟器工具栏及 EmulatorJS 菜单在下次打开时使用新语言。原生模拟器内部菜单和游戏内容使用各自的语言设置。

游戏名称、简介、版本原文、玩家昵称、ROM 路径与存档键均保持原样。服务器或模拟器返回的原始诊断也可能保留原文，避免改变故障证据。

## 添加或修改文案

- `web/i18n.js` 提供语言选择、插值和日期、数字格式化；它只更新明确标记的界面元素。
- 静态 HTML 使用 `data-i18n="中文原文"`，属性使用 `data-i18n-aria-label`、`data-i18n-title` 等对应标记。
- 动态界面通过 `t("中文原文", {name: value})` 获取纯文本。插入 HTML 模板时仍须调用 `escapeHTML`；翻译函数不会替调用者处理 HTML。
- 英文词条在 `web/i18n-en.js`。占位符使用 `{name}`，中英文保留相同参数名，完整句子作为词条，避免拼接语序。
- 浏览器播放器的服务端文案位于 `retroone/i18n.py`。EmulatorJS 的英文语言标识是 `en-US`，应用偏好标识是 `en`。

新增语种时，还需扩展前后端支持列表、设置验证、语言菜单和浏览器语言协商，不能只增加一个词典文件。翻译资源与主脚本使用内容版本标识，发布时应一起部署。

```sh
node --test tests/test_i18n.cjs tests/test_review_ui.cjs tests/test_library_management_ui.cjs
python -m pytest -q tests/test_interface_settings.py
```

验收时检查玩家隔离、语言保存失败、慢请求后切换玩家、输入框与键盘/手柄焦点、手机布局，以及切换语言期间游戏 iframe 和存档键是否保持不变。
